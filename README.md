# Genuine International — Repository Router

> **Canonical HYROBOOKS engineering has moved to the private `officegenuineinternational-gif/HYROBOOKS` repository.**

This public repository is retained for generic Genuine International tooling, historical documentation, and non-sensitive examples. It is **not** an authoritative source for HYROBOOKS application code, runtime configuration, inventory/accounting policy, local executor behavior, production deployment, or business data.

## Mandatory routing

1. HYROBOOKS code, dashboard, agents, database/schema, calculations, inventory/accounting logic, local executor, CI/CD, production deployment, and runtime evidence belong in the dedicated `HYROBOOKS` repository.
2. HYROBOOKS-related documents already present here are historical context only when they conflict with the dedicated repository.
3. Never copy live business data, credentials, customer/vendor documents, runtime databases, state folders, backups, or local evidence into this public repository.
4. Generic tooling genuinely independent of HYROBOOKS may continue here through a branch and pull request.

## Source of truth

For HYROBOOKS work, the dedicated private repository and its `AGENTS.md` / `docs/SOURCE_OF_TRUTH.md` control. A green workflow or document in this repository does not authorize a HYROBOOKS production action.
